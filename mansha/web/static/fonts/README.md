# Fonts (served locally by the web UI; no request to Google or any CDN)

From the Fontsource npm packages, version 5.3.0 (@fontsource/inter, roboto, alexandria, noto-kufi-arabic), added 31 Oct 2026.
All four families are under the SIL Open Font License 1.1 (see LICENSE-*.txt).
Typefaces follow the UAE Design System: Roboto (English body), Inter (English headings),
Noto Kufi Arabic (Arabic body), Alexandria (Arabic headings).
