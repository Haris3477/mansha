# Mansha origin check: plastic packing articles

**Result: No CEPA preference for this tariff line: the normal (MFN) rate applies**

## Summary

This tariff line is excluded from India's CEPA concessions, so the reduced rate under the trade agreement (CEPA rate) cannot be claimed. As a result, the normal import duty rate, charged when no trade-agreement preference is claimed (MFN rate), applies regardless of the product's origin. No duty savings apply to this shipment.

## Product classification

The product is classified under tariff code 39239090, covering other plastic articles for packing under heading 3923, with high confidence. You should confirm this code with Indian customs or a customs broker before shipping. [1][2][3]

## Duty comparison

| Normal (MFN) rate | CEPA rate | Estimated saving |
|---|---|---|
| 15% | Excluded | none, because the tariff line is excluded from CEPA preference |

Under the India-UAE CEPA, the normal (MFN) rate is 15%, and there is no preferential CEPA rate because this line is excluded. Consequently, no duty saving applies. [1][2][3]

## Rule of origin and result

This tariff line is excluded from India's CEPA concessions. Because the line is excluded, the rule of origin does not matter for this product and was not checked. The normal customs duty applies regardless of origin. [1][2][3]

## Important notes

- Estimate on the shipment value given. India charges duty on the assessable (CIF) value at import, so actual amounts will differ. Shown in the shipment's own currency; never converted. [1][2][3]
- CEPA rates reduce Basic Customs Duty (BCD) only. IGST, GST compensation cess, SWS and any anti-dumping or safeguard duty still apply. [1][2][3]
- The normal import duty rate applies to this product even if it meets origin rules, because this tariff line is excluded from preferential treatment. [1][2][3]
