# Mansha origin check: plastic packing articles

**Result: No CEPA preference for this tariff line: the normal (MFN) rate applies**

## Summary

The tariff line for plastic packing articles is excluded from India's CEPA concessions, so the normal (MFN) rate applies whatever the product's origin. No CEPA rate or saving is available for this shipment.

## Product classification

The tariff line is 39239090, Other (heading 3923: plastic articles for packing), and Mansha's confidence in this classification is high. You should still confirm this code with Indian customs or a customs broker before shipping. [1][2][3]

## Duty comparison

| Normal (MFN) rate | CEPA rate | Estimated saving |
|---|---|---|
| 15% | Excluded | none, because the tariff line is excluded from CEPA preference |

The agreement is the India-UAE CEPA, under which the normal (MFN) rate is 15% and the CEPA rate is excluded for this line. No saving applies because the tariff line is excluded from CEPA preference. [1][2][3]

## Rule of origin and result

The rule of origin does not matter for this line because it is excluded from CEPA preference. The normal (MFN) duty applies whatever the product's origin, so the product's origin is not checked. This is because the line is excluded from India's CEPA concessions. [1][2][3]

## Important notes

- Estimate on the shipment value given. India charges duty on the assessable (CIF) value at import, so actual amounts will differ. Shown in the shipment's own currency; never converted. [1][2][3]
