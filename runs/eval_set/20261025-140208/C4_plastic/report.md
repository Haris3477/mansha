# Mansha origin check: plastic packing articles

**Result: No CEPA preference for this tariff line: the normal (MFN) rate applies**

## Summary

this tariff line is excluded from India's CEPA concessions, so the normal (MFN) rate applies whatever the product's origin. As a result, no CEPA rate can be claimed for this product.

## Product classification

The product is classified under tariff line 39239090, Other (heading 3923: plastic articles for packing). Mansha's confidence in this classification is high, but you should confirm it with Indian customs or a customs broker before shipping. [1][2][3]

## Duty comparison

| Normal (MFN) rate | CEPA rate | Estimated saving |
|---|---|---|
| tariff 15%, effective 15% | Excluded | none, because the tariff line is excluded from CEPA preference |

The India-UAE CEPA does not apply to this tariff line; the normal (MFN) rate for this product is 15%, effective 15%. The CEPA rate is excluded, so no reduced rate is available. Consequently, there is no estimated saving. [1][2][3]

## Rule of origin and result

Because this tariff line is excluded from CEPA preference, the rule of origin does not apply. The product's origin is not checked, and the normal (MFN) rate applies regardless of origin. [1][2][3]

## Important notes

- This line is excluded from CEPA preference, so the normal (MFN) rate applies even if the product meets the rule of origin. [1][2][3]
