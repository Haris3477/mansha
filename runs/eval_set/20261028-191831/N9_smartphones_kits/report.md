# Mansha origin check: smartphones

**Result: Not eligible: the normal (MFN) rate applies**

## Summary

The product does not meet the rule of origin, so the normal (MFN) rate applies. The main failed check is the minimal operations test.

## Product classification

The product is classified under tariff line 85171300, described as Smartphones. Mansha's confidence in this classification is medium, and you should confirm the code with Indian customs or a customs broker before shipping. [1][2][3]

## Duty comparison

| Normal (MFN) rate | CEPA rate | Estimated saving |

| 20% (effective 20%) | 0% | none, because the product does not qualify |

Under the India‑UAE CEPA, the normal (MFN) duty is 20% and the CEPA rate is 0%. Because the product does not qualify, no saving applies. [1][2][3]

## Rule of origin and result

The rule of origin requires a change in tariff heading (CTH) and at least 40% value addition (VA). CTH means each non‑originating input must be classified in a different four‑digit heading than the product, and VA is the share of the product's price that does not come from non‑originating materials, calculated on an FOB basis. The final manufacture in the UAE passed, but the minimal operations check failed because only simple assembly, packaging and labelling were performed. The CTH check failed because a non‑originating input, smartphone assembly kits, is in the same heading 8517 and accounts for 88.89% of the price, exceeding the 10% de minimis threshold. The VA check failed because the build‑down was only 11.11% against the required 40% on an FOB basis. [4]

## Important notes

- The code 85171211 you gave is India's older HS 2017 code for this product; India's current tariff line is 85171300. [1][2][3]
- '+' in a rule is read as 'and' (both tests must pass). The agreement does not define '+', so this is Mansha's interpretation. [4]
- Operations and final manufacture are the exporter's own declaration. [4]
- 'Direct labour cost' and 'direct overhead cost' are not defined in the agreement. [4][5][6]
- By interpretation, de minimis helps only the tariff-shift part of a rule, not the VA percentage. [5][6]
- India's CEPA tariff schedule (Annex 2A) lists this product under the older HS 2017 code 8517 12 11. [1][2][3]
- The agreement does not specify whether the build‑down and build‑up methods use the same threshold, except for a 5‑point Ex‑Works adjustment. [4][5][6]
