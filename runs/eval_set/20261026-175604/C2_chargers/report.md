# Mansha origin check: battery chargers

**Result: Not eligible: the normal (MFN) rate applies**

## Summary

The product does not qualify for the CEPA rate, so the normal (MFN) rate of 20% applies. This is because the product failed the final manufacture, minimal operations, tariff shift, and value addition checks. No saving is available.

## Product classification

The product is classified under tariff line 85044030 for battery chargers, and Mansha's confidence in this classification is high. However, the code should be confirmed with Indian customs or a customs broker before shipping. [1][2][3][4]

## Duty comparison

| Normal (MFN) rate | CEPA rate | Estimated saving |
|---|---|---|
| 20% | 0% | none, because the product does not qualify |

The India-UAE CEPA provides a normal (MFN) rate of 20% and a CEPA rate of 0% for this tariff line. Because the product does not qualify, no saving applies and the normal rate will be charged. [1][2][3][4]

## Rule of origin and result

Under the rule of origin, the product must undergo a change in tariff heading—meaning each non‑originating input must be classified in a different 4‑digit heading—and achieve at least 40% value addition. The final manufacture check failed because the last manufacturing step did not occur in the UAE, and the minimal operations check failed because only simple packaging and labeling were performed. Additionally, the tariff‑shift test failed as one non‑originating input in the same heading represents 88% of the price, above the 10% de minimis, and the value addition is only 12%, below the 40% threshold. [5]

## Important notes

- Mansha has not checked whether India charges anti-dumping duty on this product; check with Indian customs or a customs broker. [1][2][3][4]
- '+' in a rule is read as 'and' (both tests must pass). The agreement does not define '+', so this is Mansha's interpretation. [5]
- Operations and final manufacture are the exporter's own declaration. [5]
- A lower 15% rate under Notification 45/2025-Customs (S.No. 323) applies only for electric-vehicle manufacture; Mansha uses the general 20% rate. [1][2][3][4]
